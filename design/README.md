# Design references

Static mockups the rebrand was built against. **Not shipped** — they live here
rather than in `user/public/` so they are versioned but never served, and never
appear at a public URL.

| File | What it is |
|---|---|
| `marketing-mockup.html` | Approved marketing/landing design — BantaHR indigo `#4F46E5` |
| `admin-dashboard-mockup.html` | Admin console design: KPI tiles, payroll card, attendance breakdown |
| `marketing-mockup-v1-violet.html` | Superseded first pass on Appt's `#5b5bd6`. Kept for reference; safe to delete |

Open directly in a browser — each is self-contained apart from the webfonts.

See `REBRAND-MIGRATION.md` for the decisions these encode and
`BRAND-TEST-PLAN.md` for how conformance is enforced.
